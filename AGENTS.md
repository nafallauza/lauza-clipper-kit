# Lauza Clipper Kit

Read `skills/lauza-clipper/SKILL.md`, then the specific document it routes to.
This file is the common entrypoint for Codex, Claude, Antigravity and other agents.

- Approved visual direction: black, gray and selective yellow; rectangular
  neo-brutalism in 2D. Natural footage colors remain allowed. No 3D by default.
- Preserve source A/V timing and true word intervals. Do not invent alignment.
- Subtitles only on speaker footage; no black letter outlines or icon plates.
- SFX follow visible actions; no added music unless the user requests it.
- Scope follows the current request: analysis means analysis. When execution
  is authorized, finish the implementation and relevant checks without asking
  again about routine reversible steps.
- `timothy-reference` is a verified visual example, not a universal timeline.
  Build fresh semantic beats, crop and anchors for every new clip.
- This is a general podcast clipper kit. Speakers/podcasts can change on every
  job. Read `brands/lauza/style.json` for shared visual identity; identify the
  active speaker in each shot. Do not reuse Timothy's identity or coordinates.
- Keep Lauza and Vordev separate. Ask for a Vordev brand brief if none is supplied.
- Keep media, credentials, caches, dependencies and renders outside Git.
  New production jobs are ignored by default; review before tracking their files.
- Use bounded searches/reads. Preserve other people's edits. Do not push or
  publish externally without the user's instruction.
