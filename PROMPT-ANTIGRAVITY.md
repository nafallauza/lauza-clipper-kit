# Prompt untuk Antigravity / Claude / Codex

Salin blok yang sesuai. Isi path input dengan file asli pada mesin tujuan.

## Mulai klip baru — analisis dahulu

```text
Bekerja di repo Lauza Clipper Kit ini.
Baca AGENTS.md, skills/lauza-clipper/SKILL.md, docs/STYLE.md dan docs/WORKFLOW.md.
Video input: [PATH_VIDEO].
File timestamp kata akustik: [PATH_WORDS_JSON atau belum tersedia].

Analisis dulu. Buat beat plan berisi rentang waktu, ucapan, wajah/cutaway,
aksi ikon/grafik, susunan dan arah subtitle, target zoom, serta kontak SFX.
Terapkan gaya kotak neo-brutalism 2D hitam–abu–kuning; tanpa 3D dan musik.
Wajah harus utuh. Subtitle tanpa outline hitam; ikon tanpa pelat hitam.
Jangan mengarang timestamp atau menyalin angka/beat contoh Timothy.
Belum perlu render final sampai aku menyetujui rencananya.
```

## Setelah rencana disetujui

```text
Eksekusi beat plan yang sudah disetujui. Lanjutkan sampai artefak video selesai.
Buat job terpisah dan pertahankan versi pembanding. Pakai kata/timing asli,
periksa crop per shot, gerak zoom, keterbacaan HP, SFX dan loudness.
Jalankan pemeriksaan yang relevan, render file versi baru dan simpan laporan
singkat. Jelaskan bagian yang benar-benar diuji dan batas review audiovisual.
Tidak perlu meminta konfirmasi ulang untuk langkah rutin yang bisa dibalik.
```

## Push repo — hanya bila memang hendak mengunggah

```text
Aku mengizinkan push repo kit ini ke https://github.com/nafallauza/lauza-clipper-kit.git.
Baca AGENTS.md. Periksa git status dan file yang akan dikirim.
Upload hanya template, kode, dokumentasi dan font berlisensi di repo ini.
Jangan sertakan video pribadi, transkrip job produksi baru, media audio,
arsip ZIP/LUT, credentials, node_modules, cache atau out/.
Jangan force-push atau menghapus perubahan remote. Tangani perubahan remote
dengan mempertahankan pekerjaan yang sudah ada. Jalankan pemeriksaan relevan,
buat commit jika diperlukan, push, dan laporkan URL repo serta commit akhirnya.
```
